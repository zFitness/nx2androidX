The upstream's pull requests, distilled into a diagnosis: the port-failures skill
(agent/.agents/skills/port-failures/). It is the offline answer to "what is this symptom and
has it been fixed": five reference documents (a build that stops, the shader split, the
symptoms on the device, what the device showed, and the method - how to measure a title, read
a crash report, use the probes, and where a fix belongs), and a case index of every upstream
pull request, searchable with the tool tree's memory_search.py. It says where each fix lives - a core
rule or one game's profile - and whether this fork already has it.
